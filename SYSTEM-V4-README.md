# REMS Control V4 — студенти, групи й проєкти

- Зміна `group` у картці студента зберігається у REMS Control та публікується у `rems_public_profiles`.
- Немає жорсткого повернення студентів у РЕМС-34/РЕМС-44.
- У розділі «Студенти» верхня кнопка стає «+ Новий студент».
- У розділі «Проєкти» верхня кнопка стає «+ Новий проєкт».
- В інших розділах «Новий проєкт» не показується.
- Новий студент із новою назвою групи публікується автоматично; сайт сам створить вкладку цієї групи.
- «Скасувати» у вікні нового проєкту закриває його без обов'язкового заповнення полів.
