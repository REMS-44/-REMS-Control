REMS Control v44.0 — правила Firestore для «Режисерської лабораторії»

Додайте ці блоки ВСЕРЕДИНУ чинного:
match /databases/{database}/documents { ... }

match /rems_directing_lab_schema/{schemaId} {
  allow get: if true;
  allow list, create, update, delete: if request.auth != null;
}

match /rems_directing_lab_work/{labKey} {
  allow get: if true;
  allow list: if request.auth != null;
  allow create, delete: if request.auth != null;

  // Студент за персональним ключем може змінювати тільки власну робочу частину.
  allow update: if request.auth != null
    || request.resource.data.diff(resource.data).affectedKeys().hasOnly([
      'answers',
      'sectionStates',
      'stages',
      'projectTitle',
      'updatedAt',
      'studentUpdatedAt'
    ]);
}

match /rems_directing_lab_feedback/{labKey} {
  allow get: if true;
  allow list, create, update, delete: if request.auth != null;
}

Колекція rems_student_media вже має allow read: if true — це дозволяє студентській
лабораторії показувати те саме фото, що й вкладка «Студенти».
