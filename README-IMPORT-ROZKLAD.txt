REMS Control v5.5 — імпорт із REMS-РОЗКЛАД

1. У REMS-РОЗКЛАД відкрийте «Налаштування» → «Експорт даних».
2. У REMS Control відкрийте «Розклад занять».
3. Натисніть «Імпорт із REMS-РОЗКЛАД».
4. Залиште вибраними РЕМС-34 та/або РЕМС-44.
5. Оберіть JSON-файл, експортований із REMS-РОЗКЛАД, перевірте попередній перегляд і натисніть «Імпортувати розклад».

Повторний імпорт замінює лише попередні імпортовані записи для вибраних груп.
Заняття, додані вручну в REMS Control, не видаляються.
