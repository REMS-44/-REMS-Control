# REMS-Control v46.8.1 - Arthur clean start

Точкова службова версія для очищення тестової комунікації Артура Позняка.

- На сторінці Артура у викладацькій лабораторії є кнопка **«Очистити тестові діалоги й активність»**.
- Вона видаляє викладацький feedback-документ, студентські thread/review записи та історію activity у sectionStates.
- Не видаляє відповіді студента, матеріали, файли, Google Drive, проєкт або персональний accessKey.
- Кнопка доступна тільки для студента, ім’я якого містить «Позняк Артур».

Після очищення можна продовжити тестування з чистою історією.
