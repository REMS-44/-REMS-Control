# REMS-Control v46.3

Додано окремий екран «Посилання студентів» у Режисерській лабораторії. Викладач може одним натисканням скопіювати всі чинні персональні посилання РЕМС-44, РЕМС-34 або обох груп. Існуючі ключі доступу не змінюються.

# REMS-Control v46.2

Оновлення режисерської лабораторії:
- уточнена логіка 1.4: проблема як найширший рівень, тема як конкретизація, ідея як авторська думка, надзавдання як режисерська мета розкриття проблеми;
- Word-експорт усього 1.2 одним документом;
- окремі Word-експорти 1.3.1 документальних, 1.3.2 художніх матеріалів і 1.3.3 режисерського блокнота;
- у Word 1.3 зберігаються активні посилання на джерела та прикріплені файли;
- Word-експорт усього 1.4 одним документом;
- ті самі експорти доступні викладачу в адмін-перегляді роботи студента.
- викладач може окремо для кожного робочого пункту залишити коментар, оцінку / бал і статус;
- викладач може відредагувати відповідь студента безпосередньо в адмін-перегляді та зберегти її у робочий документ;
- студент бачить відгук безпосередньо під тим пунктом, якого він стосується, включно зі статусом, оцінкою і позначкою про редакцію викладачем;
- нові відгуки до окремих пунктів враховуються у сповіщеннях та індикаторах розділів.
