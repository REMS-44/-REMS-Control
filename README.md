# REMS Control v0.3 — Firebase

Хмарна версія REMS Control.

## Що змінило
- база REMS Control підключена до Cloud Firestore;
- одна база даних може відкриватися на комп'ютері, iPad і телефоні;
- зміни проєктів, дат і призначень студентів записуються у Firestore;
- сторінка слухає зміни Firestore і автоматично оновлюється;
- локальний кеш лишився як резерв на випадок тимчасової відсутності зв'язку;
- початкові дані v0.2 автоматично завантажуються в Firestore, якщо хмарна база ще порожня.

## Файли для GitHub
Замініть / додайте у репозиторії:
- `index.html`

- `firebase-config.js`
- `README.md`

## Важливо: Firestore Rules
Сайт зможе читати й записувати дані лише якщо правила Firestore це дозволяють.
Для першого тесту можна тимчасово дозволити доступ до колекції `rems_control`, а потім обов'язково додати авторизацію та закрити правила.

Firebase web config не є паролем; захист даних забезпечують Firestore Security Rules та авторизація.
