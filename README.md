# REMS-Control v46.0

Додано 1.4 «Ідейно-тематичний аналіз»: проблема, тема, ідея, надзавдання (мета) і розгорнутий конструктор головного конфлікту.

Конфлікт розкладається на зміст, дві сторони, прагнення кожної сторони, конкретні матеріали їх сценічного прояву, предмет конфлікту та підсумкове формулювання.

Структура синхронізована у студентській і викладацькій частинах. Старі відповіді problem/theme/idea/conflict зберігаються завдяки тим самим ідентифікаторам полів.
