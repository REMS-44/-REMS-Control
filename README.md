# REMS Control v45.1 — робоча база матеріалів

## Що змінено

- Розділ 1.3 «Пошук, дослідження та збір матеріалу» більше не подається на перевірку.
- Статус розділу: «Робочий етап» або «Первинний збір сформовано».
- Замість «Подати на перевірку» є «Зберегти матеріали» та «Позначити первинний збір сформованим». Позначення не блокує подальше редагування.
- Додано підсумок етапу з кількістю документальних, художніх матеріалів, нотаток та важливих знахідок.
- До кожної картки можна додавати необмежену кількість посилань: Google Drive, YouTube, сайти, статті, архіви тощо.
- Для великих файлів використовується надійний Drive-native workflow: кнопка відкриває персональну папку Google Drive, файл завантажується туди засобами самого Drive, після чого посилання додається у картку матеріалу. Це прибирає ліміт 25 МБ саме для дослідницького розділу та не залежить від нестабільного Apps Script POST-моста.
- Старі вже завантажені файли в картках не губляться і залишаються видимими.
- У викладацькій частині для 1.3 прибрано статус погодження/доопрацювання; показується робочий підсумок і самі матеріали.

## Важливо

Файл `drive-upload-apps-script.gs` залишено в архіві як експериментальний міст, але v45.1 не залежить від нього для розділу 1.3. Для великих файлів рекомендовано використовувати персональну папку Google Drive та додавати посилання в лабораторію.
