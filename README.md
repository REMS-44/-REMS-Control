# REMS Control v46.8 - Simplified Communication

Основна мета версії: спростити комунікацію викладача і студента та стабілізувати персональні студентські сторінки.

## Що змінило
- Виправлено падіння студентської сторінки через відсутні helper-функції у v46.7.
- Студент має одне центральне місце: кнопка `Повідомлення` у верхній частині лабораторії.
- При натисканні повідомлення студент переходить до конкретного пункту і відкриває переписку саме цього пункту.
- Під кожним пунктом залишається лише компактна кнопка переписки, без великих дублюючих плашок.
- Прибрано дублювання повідомлень у верхній навігації, банерах розділів і окремому inbox на сторінці.
- Системні браузерні сповіщення прибрано з інтерфейсу. Комунікація зосереджена всередині лабораторії.
- Для викладача вся нова активність зібрана в одному розділі `Активність`.
- Картки студентів більше не дублюють червоні/помаранчеві індикатори активності.
- Натискання на подію в `Активності` відкриває конкретного студента і конкретний пункт.
- Історія переписки кожного пункту зберігається і видима обом сторонам.
- Новий коментар викладача не підміняє попередній: він додається до історії.
- Старі загальні коментарі до розділів не видаляються, але відображаються компактно як попередні нотатки.

## Дані
Структура Firestore не змінена. Існуючі відповіді, посилання, матеріали, коментарі та історія переписки зберігаються.
