# REMS-Control v46.5

Оновлення комунікації Режисерської лабораторії.

- У кожного пункту є компактна кнопка «Переписка», повний діалог відкривається у модальному вікні.
- Попередні коментарі викладача більше не зникають: нові версії додаються до історії.
- Студент і викладач бачать єдину хронологію повідомлень до конкретного пункту.
- Студент може повідомити про виправлення або написати коротке повідомлення викладачу.
- Центр активності викладача показує конкретний внесений текст, матеріал або назву завантаженого файла.
- Натискання на подію активності відкриває студента і прокручує сторінку одразу до відповідного розділу або пункту.
- Старі поточні коментарі сумісні: під час наступного збереження вони автоматично стають першим елементом історії.
- Нових колекцій Firestore не додається. Історія студента зберігається всередині дозволених answers/sectionStates, історія викладача у rems_directing_lab_feedback.
