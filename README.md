REMS-Control v47.8

- Чернетка тепер зберігається окремо під кожним пунктом лабораторії.
- Виправлено втрату незбереженого тексту при Firestore-оновленнях: локально змінені пункти зберігаються у формі під час перерендеру.
- Статуси викладача «Переглянуто», «Доопрацювати», «Погоджено», повторне подання та оцінка видно безпосередньо біля конкретного пункту.
- Погоджені пункти блокуються від випадкового редагування.
- Повернуто шкалу виконання у відсотках. Вона рахує тільки пункти зі статусом «Погоджено», а не просто заповнені поля.
- Загальну кнопку «Зберегти чернетку» під підрозділом прибрано; подання підрозділу на перевірку залишено.
