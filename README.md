REMS-Control v47.2

- Верхня навігація: окремі вкладки Розділ 1 / Розділ 2; підрозділи показуються тільки для активного розділу.

- Word: окремі 2.1, 2.2, 2.3, 2.4 плюс весь Розділ 2, для студента й викладача.

- У викладацькій лабораторії додана одноразова дія «Очистити назви проєктів».
