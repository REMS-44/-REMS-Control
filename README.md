# REMS-Control v47.0 - Сценарно-драматургічна основа

Додано РОЗДІЛ 2 «Сценарно-драматургічна основа».

Структура:
- 2.1. Сюжет / логіка подієвого розвитку.
- 2.2. Композиція: експозиція, зав’язка, розвиток дії, кульмінація, розв’язка, фінал.
- 2.3. Архітектоніка: загальна модель та таблиця епізодів / блоків.
- 2.4. Сценарний план.

До кожного пункту додано студентську теорію. «Розвиток дії» навмисно зроблено великим полем. Для архітектоніки та сценарного плану використано динамічні таблиці з додаванням рядків.

Викладач бачить, редагує, коментує та оцінює нові пункти через наявну систему переписки. Додано Word-експорт усього Розділу 2 для студента і викладача.

Версія збережена на основі v46.8.1, тому точкова функція очищення тестових діалогів Артура Позняка лишається.
