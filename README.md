# REMS-Control v44.4 - вихідні параметри проєкту

- 1.1 «Обґрунтування вибору» тепер завжди стоїть першим.
- 1.2 «Вихідні параметри проєкту» стоїть другим.
- Старий «Паспорт проєкту» прибрано зі структури, але наявні відповіді студентів у Firestore не видаляються.
- Додано теорію до назви, форми, жанру, масштабу, майданчика, формату, аудиторії, дати/часу та хронометражу.
- У формах залишено: концерт, шоу, шоу-вистава / вистава, вечір, церемонія, конкурс, фестиваль, свято, презентація.
- Перформанс, гепенінг, флешмоб, карнавал та інсталяція не включені.
- У формі не використовуються прикметникові характеристики. Вони належать до жанру.
- Телевізійний і суто відеоформат не включені.
- Теоретичні тексти відкриваються у модальному вікні, форма залишається компактною.
- Поля на широкому екрані розміщуються по два в ряд, на телефоні по одному.
- У нових теоретичних текстах не використано довге тире.

Для вже збереженої схеми міграція виконується при завантаженні без видалення студентських відповідей.
