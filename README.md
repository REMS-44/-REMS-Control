# REMS Control v44.0 — Режисерська лабораторія-конструктор

## Що додано
- Живий конструктор структури лабораторії у REMS-Control.
- Розділ має вступний теоретичний матеріал + окремі робочі пункти.
- Типи пунктів: короткий текст, великий текст, таблиця, файл, посилання, чекліст, матеріал/приклад.
- Нові розділи можна додавати впродовж семестру; студентські відповіді зберігаються окремо від структури.
- Розділ можна підготувати як чернетку й опублікувати пізніше.
- У студентській лабораторії показуються фото, ПІБ, група, назва проєкту та прогрес.
- Адаптивний інтерфейс для desktop / iPad / phone.
- Персональна папка Google Drive для кожного студента.
- Завантаження файлів у Firebase Storage (після публікації Storage Rules).
- Таблиці заповнюються прямо на сторінці.
- Коментарі й статуси викладача на рівні розділу.
- Кнопка «Завантажити все» формує ZIP: texts.txt, CSV-таблиці, список посилань і список завантажених файлів.

## Після завантаження на GitHub Pages
1. Оновіть Firestore Rules блоками з `FIREBASE-RULES-DIRECTING-LAB.txt`.
2. Для завантаження студентських файлів увімкніть Firebase Storage та додайте правила з `FIREBASE-STORAGE-RULES-DIRECTING-LAB.txt`.
3. У REMS-Control відкрийте «Режисерська лабораторія» → «Конструктор лабораторії» → «Опублікувати структуру».
4. Для кожного студента можна вставити персональне посилання на Google Drive.

## Важливо
Google Drive у v44.0 використовується як персональна папка-посилання. Файли, які студент завантажує безпосередньо через лабораторію, зберігаються у Firebase Storage. Автоматичне фізичне копіювання цих файлів у Google Drive потребує окремої Google Drive API/OAuth інтеграції й не ввімкнене в цій версії.
