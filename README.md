## Пряме завантаження у Google Drive
Код підтримує пряме завантаження файлів у персональну папку студента і автоматично створює в ній:
- `01 Документальні матеріали`
- `02 Художні матеріали`
- `03 Режисерський блокнот`

Для цього потрібне одноразове розгортання Google Apps Script:
1. Створіть новий Apps Script у Google Drive того акаунта, який має доступ до студентських папок.
2. Вставте в нього код із `drive-upload-apps-script.gs`.
3. Deploy -> New deployment -> Web app. Execute as: Me. Access: Anyone with the link.
4. Скопіюйте URL вебзастосунку.
5. Вставте його у `drive-upload-config.js` у `window.REMS_DRIVE_UPLOAD_ENDPOINT`.

Поки URL не підключений, лабораторія не імітує Drive-завантаження: студент бачить пряме посилання на свою папку.

Файли до 25 МБ. Метадані і режисерські нотатки зберігаються у Firestore, самі матеріали після підключення мосту — у Google Drive.
