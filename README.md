# REMS-Control v47.1 - уточнений Розділ 2

Зміни:
- РОЗДІЛ 2 «Сценарно-драматургічна основа» поділено на окремі підрозділи 2.1, 2.2, 2.3, 2.4.
- У верхній навігації є окремі переходи до Розділу 1 і Розділу 2 та до кожного підрозділу.
- Переписано теорію сюжету: для номерних форм сюжет описується буквально як послідовність того, що відбувається на проєкті.
- Кульмінація сформульована коротко як найвища точка розвитку конфлікту.
- Архітектоніку спрощено до драматургічної будови епізодів і блоків.
- Сценарний план відокремлено від монтажного листа. Він містить епізод / блок, сценічну одиницю, короткий зміст, учасників і хронометраж.
- Word-експорт усього Розділу 2 збережено.
- Для Артура Позняка кнопка «Почати Артура з нуля» тепер повністю очищає всі тестові відповіді, матеріали, таблиці, діалоги, статуси, оцінки й активності, але зберігає персональне посилання, Drive та прив’язаний проєкт.
