REMS Control v49.4.54 - серверна частина push

ВАЖЛИВО: завантаження файлів на GitHub Pages НЕ розгортає Firebase Cloud Functions.
Після оновлення сайту один раз розгорніть три функції з кореня цього проєкту:

npx firebase-tools login
npx firebase-tools use rems-control
npx firebase-tools deploy --only "functions:registerDirectingLabPush,functions:onDirectingLabTeacherReply,functions:onDirectingLabStudentReply"

Якщо Firebase CLI вже авторизований, перший рядок можна пропустити.
Після успішного deploy оновіть REMS Ctrl+F5 і знову натисніть «Увімкнути push».

Якщо реєстрація все ще не пройде, v49.4.54 покаже точний серверний етап і текст помилки замість просто «internal».
